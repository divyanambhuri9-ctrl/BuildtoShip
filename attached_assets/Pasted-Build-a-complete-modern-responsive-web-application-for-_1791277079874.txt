## 6. GEMINI AI QUESTION GENERATION

Use Gemini to generate interview questions based on:

* Interview type
* Job role
* Difficulty
* Number of questions

The AI should return structured JSON.

Example format:

{
"questions": [
{
"question": "Explain the difference between a stack and a queue."
}
]
}

Validate the response before using it.

If Gemini fails, show a useful error message rather than crashing the application.

To reduce API usage:

* Generate questions ONCE when an interview starts.
* Do not call Gemini repeatedly for the same question.
* Store generated questions in Supabase.
* Never make Gemini calls on every UI render.
* Do not automatically regenerate questions.
* Use 5 questions as the default.
